## 2. 演员表：大约 15 个人

- 两位选手，每人身后站**两个队友**。队友几乎一直出现在背景里，构成画面的第二层。
- 三位评委坐在王座上，有反应镜头，其中一位老人在哭，是喜剧点。
- DJ 和主持各一位，副歌歌手两位。
- 观众席里有角色客串（鸣人、佩恩），**歌词点到谁，就切到谁的反应**。比如唱到「你站在他的心上……」切鸣人一脸震惊，唱到「连佩恩都听清」切佩恩坐在观众席里笑。

## 3. 镜头语言

- **节奏比我们设想的慢**：63 到 78 个镜头（按检测阈值不同），平均约 3.4 秒，中位数 3.6 秒。一个镜头常常装下一到两句词，不是一句一刀。
- **运镜很克制**：基本是固定机位、慢推和轻微手持，几乎没有花哨的运镜。好看的地方在于**画面里放了谁、谁在反应**，不在于运镜。
- 反复出现的镜头：
  1. **贴脸对峙**：两人侧脸，鼻尖几乎碰到，话筒夹在中间，用在最狠的几句；
  2. **前景虚化的对手头发 + 正在唱的人**（过肩）；
  3. **唱的人特写，队友虚在身后**；
  4. **指向镜头**、**把话筒伸向镜头 / 观众**；
  5. **场馆高位全景**，地上的节目 logo 交代空间；
  6. **评委反应**、**观众席角色反应**；
  7. **分屏入场**；
  8. **灭灯 + 单束追光**，只在高潮用一次。
- 场景从头到尾只有一个：红黑配色的场馆，红色 LED，节目 logo 印在地板和大屏上。灯光、服装、站位全片一致，这就是「像一档真节目」的来源。

## 4. 歌词

- **对话式**：通篇对「你」说，B 段大量引用 A 段的原话再反驳（「你说陪伴最珍贵」；「你那句『喜欢他』」对上「我那句『喜欢他』」）。
- **弹药是角色关系和原作事件**，不是冷知识：宁次的三十二掌、佩恩战的告白、柔拳、白眼、查克拉怪力、佐助叛逃。情绪核心是一段感情。
- **句子长短差很多**：短的只有「拜托！！！」「你很强」，长的近 20 字；大量排比（「等人帮，等人挡」「等他回头，等他开口，等他……」「嫌他吵，嫌他闹」）。
- **留一个停顿揭晓**：「因为你的最强忍术叫做……」灭灯，停一下，然后揭晓。
- **押韵宽松但持续很久**：长段落一直押 ang 韵（场、上、量、常、膀、光、讲），不是四句一换。
- **第三种声音**：旋律副歌由另一位歌手唱，拟声（啦啦、哒哒、嘟嘟）当间奏。
- **弱者翻盘**：安静的那个后唱、唱得更长、情绪更高，赢下全场；最后一句把问题抛给观众（「你们站哪边」）。

## 5. 对我们流水线的影响

1. 新增 `show` 节目模板：冷开场、主持开场、分屏入场、对峙、副歌、A 段、间奏、B 段、高潮停顿、副歌回归、互动结尾，时长 3–4 分钟。
2. 演员表支持多种角色：选手、队友、评委、主持 / DJ、副歌歌手、观众席客串。每人一张角色卡、一张定妆图。
3. 分镜规则：
   - 歌词点名某个角色，就切这个角色的反应镜头；
   - 一个镜头装一到两句，平均约 3 秒；
   - 加上面列的 8 种镜头；运镜改成以固定和慢推为主；
   - 队友常驻在背景层。
4. 歌词规则：对话和引用原话、排比、停顿揭晓、长段押同一个韵、第三位歌手唱副歌、赢家后唱且更长、结尾抛问题给观众。
5. 声音：至少四种声音（两位选手、副歌歌手、主持）。主持的话是念的，要单独决定用 Suno 的念白段还是语音合成。
6. 包装：节目 logo 角标、固定的场馆美术（地板 logo、大屏），白色字幕，压在下方。
