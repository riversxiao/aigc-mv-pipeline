# Dreamina（即梦）与 Suno 接口对接说明

两个适配器已经留好位置，等你给我接口文档后补完：`src/aigc_mv/providers/dreamina.py`、`src/aigc_mv/providers/suno.py`。在那之前，整条流水线可以走网页手动路线：`aigc-mv ep prompts` 生成的 `units/<id>/prompt.txt` 可以直接复制粘贴到即梦网页版。

## 我需要你提供

**Dreamina / Seedance 视频**
- 提交、查询、下载三个接口的地址和鉴权方式（Header 名称、签名方式）
- 支持的模型名（Seedance 2.0 / 2.x）、时长范围、分辨率、比例
- 多图参考加音频参考（「全能参考」）的字段名；图片和音频是传 URL 还是上传文件
- 首帧模式和参考模式能不能同时带音频（有的服务商一传首帧就会悄悄丢掉音频参考）
- 价格（按秒还是按积分）和并发限制
- 「超清」放大能不能通过 API 调用

**Dreamina / Seedream 图片**（可选，用来替代 Midjourney 做定妆图和首帧）
- 生成接口、参考图字段、返回格式

**Suno**
- 生成接口：歌词、风格、标题、模型版本字段
- Extend 接口：从哪条歌、从第几秒续写
- stem 分离接口：至少要拿到人声和伴奏
- 下载格式（WAV 最好）

## 适配器要遵守的约定

| 约定 | 原因 |
| --- | --- |
| 对口型单元用参考模式（图片 + @音频1），不用首帧模式 | 有的服务商带首帧时会丢音频 |
| 时长、分辨率、比例放在请求字段里，不写进提示词 | 写进提示词的数值会被模型当成画面内容 |
| 图片缩到输出分辨率，存 PNG 再上传 | 大图会带来指纹状纹理 |
| 拿到 job id 后不重复提交 | 避免重复扣费 |
| 下载存到 `units/<id>/takes/take-N.mp4` | `ep sync` 从这里读 |
| 每次调用先过 `SpendGate.check`，结束后调用 `SpendGate.record` | 预算上限和账本 |
| Key 只从环境变量读：`DREAMINA_API_KEY`、`DREAMINA_API_BASE`、`SUNO_API_KEY`、`SUNO_API_BASE` | 不进仓库 |

## 接好以后的命令（计划）

```bash
aigc-mv ep generate projects/xxx u03          # 提交一个单元（先过花钱闸门）
aigc-mv ep generate projects/xxx --all --takes 2
aigc-mv ep song projects/xxx                   # Suno 两段生成 + Extend + stem
```
