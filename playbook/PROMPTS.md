# H3 / Seedance 六层生物力学提示词骨架

核心原则：**少堆画质形容词，按人体发力链写出「重心—肩肘—手部进出画—五指—衣发惯性—声腔口型」与明确起落幅运镜**。代码侧已内置于 [`cinema.py`](../src/aigc_mv/cinema.py)（`BIOMECH_SUNG_CN` / `GESTURE_PHASES`）与 [`prompts.py`](../src/aigc_mv/prompts.py)。

## 1. 主唱对口型单元模板（`ref2va_pose`）

```text
【音频】视频的声音就是 @音频1 本身：从第一帧到最后一帧原样保留，时间、音高、音量都不变。
【参考图】@图片1 是角色锁定五视图定妆组图（只认脸、发色与服装，不当画面出现）；@图片2 是舞台场景基准图。
【分镜】
镜头1（0.0–3.2 秒）：近景，85mm 浅景深；运镜：从起幅平稳推近一档景别，0.0 秒开始，2.6 秒停稳。
  唱：0.25–1.60 秒「上半句歌词」，1.65–3.05 秒「下半句歌词」，嘴型逐字对上 @音频1；
  肢体多拍演进：重心从后脚压向前脚，右手稳握银色有线话筒于嘴斜下方，左手先掌心向上勾指挑衅，1.5 秒气口随俯身自然下摆甩出画外，2.0 秒重音字重新从画外抬手直指镜头后收拳；衣袖与发丝慢半拍随惯性摆动。
  （同框对手：嘴一直闭着，只听不说，前 1 秒冷眼直视，后半段眉梢微挑冷笑。）
【口型】高音与长音字下颌自然大幅张开、苹果肌抬起、脖颈发力清楚，绝不抿嘴微动；鼻音「哼」或无声处双唇自然紧闭。
【肢体动态】六层发力连贯自然：1.重心随重拍前后压步转移；2.肩肘带动小臂传导发力；3.空着的手完成「起势比划→下摆出画→重音再抬手」两到三拍切换，绝不悬停僵在半空；4.五指张合分明；5.衣袖与发丝慢半拍随惯性摆动；6.换气时胸廓起伏并带眨眼挑眉。
```

## 2. 反应 / 器乐 / 武打切镜模板（`ref2va_depth`）

```text
Camera: <景别 + 焦段 + 明确推/移/摇方向与停稳拍点>
Subject & 2-Beat Micro-Acting:
  - 反应镜：嘴全程自然闭合；第 1 拍先微怔/皱眉侧耳听梗，第 2 拍转为憋笑/震惊捂嘴/缓缓点头（严禁单表情静止定格）。
  - 器乐镜：本片角色（如红粉双辫白羽鹤氅陆玲珑 / 破衣李慕玄）半身或中景亲自在舞台击鼓或抚琴，肩臂带动衣袖翻飞，鼓槌/指尖精准卡在分轨重音上（严禁只拍无身体的悬空双手）。
Depth & Lighting: 前景虚化人头或乐器边缘遮挡 + 中景清晰主体 + 背景环形观众散景三层视差；体积顶光 + 冷暖轮廓光。
Nobody speaks: 画面内无人开口唱歌，无字幕、无水印、无多余肢体。
```

## 3. 跨龄 / 状态变身模板（`fl2va_morph`）

```text
  面部骨相与衣纹在气流高光中无缝完成向青年态（_b.png）的蜕变，2.0–2.8 秒青年角色抬眸定格收势。
```

## 4. 禁用清单（代码审核自动拦截）

- **禁用词（`cinema.BANNED_WORDS`）**：`唯美 / 绝美 / 精致五官 / 完美 / 仙气 / 仙侠 / 帅气 / 美颜 / 网红 / 高颜值 / 8k / masterpiece / hyper-detailed / flawless / beautiful / handsome`（此类词汇会把写实纹理拉向塑料网红脸）。
- **禁用单图静态 `fl2va` 拍连续说唱**：定妆组图（`_sheet.png`）只作为 `Ref2VA` 身份参考输入，绝不能直接当成 `first_frame` 贴进视频第 0 帧。
- **禁用带面部关键点的 DWPose 跑高音唱段**：会压扁下颌张开幅度，导致高音女声/爆发句面部毫无动作。
