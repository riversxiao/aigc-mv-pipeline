# 入队前硬检 Checklist（定妆组图 · 双关键帧 · ControlNet 控制源）

任何镜头送入 H3 / 视频生成队列前，按其 `h3_mode` 逐项过检；**任一项 Fail → 退回重做静帧或控制源，禁止烧 GPU**。

## A. 通用五项角色与空间硬检（所有模式必检）

| # | 检查项 | 过关标准 | Fail 典型（一票否决） |
|---|---|---|---|
| 1 | **身份与发色红线** | 骨相、年龄段、发色与定妆卡 100% 一致（如陆玲珑必须红/粉双辫配白羽鹤氅；老年李慕玄必须沧桑男相破布衣） | 陆玲珑漂成黑发女子；老年说词段出现女脸或少年脸 |
| 2 | **服装与材质** | 领口、披风、袖口磨损与定妆组图一致；有真实织物纹理，无现代乱码 Logo | 西装变道袍、塑料反光皮肤 |
| 3 | **左右手与持麦/器乐** | 一手握麦于嘴斜下方不挡唇，空闲手五指完整；器乐镜必见角色头肩半身亲自演奏 | 话筒挡嘴、六指粘连、**只有一双悬空手敲鼓无身体** |
| 4 | **轴线与同框听者** | 左选手永远在左朝右，右选手永远在右朝左；非唱方双唇自然闭合 | 左右换边跳轴、听句方跟着乱张嘴 |
| 5 | **背景透视与群像来源** | 擂台灭点一致；观众席/评委席切镜基于官方/定妆底图 `img2img` 生成 | 纯文生图路人画风割裂、背景建筑坍塌 |

## B. 分轨道专项硬检

### 1. `ref2va_pose`（主唱说唱 / 高音副歌）
- [ ] **剔除面部关键点**：`DWPose` 控制视频只保留 **21 个躯干 + 双臂 + 手掌关键点**，面部 68 点已清空（确保高音下颌能被音频自由撑开）。
- [ ] **空闲手非静止**：骨骼预览中空闲手在单镜内至少有 1 次明显的进出画或高低位切换（严禁整段停在同一高度抖动）。
- [ ] **防渗色截断**：`control_strength` 设在 `0.68–0.75`，`end_percent` 设在 **`0.80–0.86`**（严禁 `1.0`）。

### 2. `ref2va_depth`（武打 / 炁浪 / 器乐 / 群像反应）
- [ ] **三层景深梯度清楚**：深度控制视频具备前景遮挡、中景主体、远景背景三层明暗分离，且自身带平滑推拉位移（非死板单帧深度图）。
- [ ] **防灰雾截断**：`control_strength` 设在 `0.62–0.74`，`end_percent` 设在 **`0.80–0.84`**（消除暗部深度灰影残留）。

### 3. `fl2va_morph`（跨年龄变身 / 状态蜕变）
- [ ] **`_a.png` 与 `_b.png` 并排校验**：首尾同机位同焦段，但年龄/姿态/气场有明确可插值的起落变化（姿态归一化差异 `>= 0.06`）。
- [ ] **零单图复用**：确认没有任何静态肖像被同时原样充当 2 个以上镜头的 `first_frame`。

## C. 落盘记录

建议存放在 `projects/<id>/edit/keyframe_qc/<shot_id>.json`（含 `shot_id, h3_mode, control_strength, end_percent, checks, pass, reviewer`），并在成片渲染后配合 `aigc-mv ep rea-audit <id> --check-flow` 做终审闭环。
