# Venue Bible 模板

场地一乱，人物再饱满也会「廉价」。每集固定场地前先出圣经，再拆镜。

## 必须锁定

1. **轴线**：谁在画左 / 画右（例：一人之下 ep02 张灵玉左、张楚岚右）。  
2. **方位**：东西南北（龙虎、水道、月亮各在哪）。  
3. **机位**：至少 A 正打 / B 反打 / C 侧 / D 俯，跨机位同模型。  
4. **材质**：真材实料描述（铜/玉/湿石/丝灯），避免塑料 CG 感。  
5. **灯光 cue**（可选 v3.2 级）：主歌 / 副歌 / 高潮色温与霓虹占比（霓虹 ≤ 约 20% 画面）。

## QC 红线

- 水道 / 岸廊跨机位不一致  
- 龙虎 / 图腾细部非同模型  
- 灯具光束数量跨镜对不上  

未过 QC 的场地，不重拍人物主镜。
