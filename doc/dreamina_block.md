# 即梦（Dreamina）视频生成被风控拦截：现状说明

## 现象

- 在编排方的沙箱里，所有 `node run`（视频节点提交）都被即梦拒绝，返回账号级风控：
  `service.20046`，`human_intervention`，命令行退出码 22。
- 被拒绝的提交 **没有扣积分**（报价和账户余额都没有变化）。
- 换了好几个模型（Seedance 2.0 系列的不同档位）都是同一个结果，说明不是某个提示词或某张图触发的，而是账号层面的限制。
- 图片生成（`text2image` / `image2image`）一切正常，所有定妆图、组图、场景图都是这样生成的。
- 运行器（`src/aigc_mv/dreamina_runner.py`）已经把这个响应识别为终态 `blocked_risk`，不会重试，也不会重复提交。

## 需要你做什么

这个限制只能在即梦账号上解除，agent 解不了：

1. 用浏览器登录即梦官网，看账号有没有“需要人工验证”“实名/手机验证”“账号异常”之类的提示，按提示完成。
2. 检查会员和积分状态，必要时开通/续费会员（视频生成通常要求会员或足够积分）。
3. 如果官网没有任何提示，在即梦的帮助/反馈入口提交申诉，说明是正常使用视频生成被风控拦截。
4. 解除后在自己电脑上运行 `dreamina-canvas auth login` 重新登录，然后先做一次最小测试：
   `python3 run_dreamina.py --units u01 --quote-only`，再正式跑。

## 怎样确认已经解除

运行 `python3 run_dreamina.py --units u01`。如果这一个单元能正常提交并拿到视频（不再出现 `service.20046`），再跑全部 44 个单元。
如果还是被拒，状态会显示 `blocked_risk`，此时不要反复重试，回到上面的第 1 到 3 步。

## 本资料包不包含

没有任何账号凭据、登录状态、即梦本地状态目录的内容，也没有编排方机器上的路径。登录要在你自己的电脑上做。
