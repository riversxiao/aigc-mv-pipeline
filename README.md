## 花费（OpenRouter 返回的 usage.cost）

- 本轮：46 张图，$2.4669（场景图 4 张 $0.1355，第二步 16 张 $0.8935，第一步 26 张 $1.4379）。另外 26 次请求被 OpenRouter 以 HTTP 403 “Key limit exceeded” 拒绝，不出图也不扣费。
- 累计（本地账本）：54 张图，$2.926。
- OpenRouter 那边显示这把 key 已经用了约 $5.09–5.42，超出了它自带的 $5.00 总额度（不会重置）。这比本地账本多出约 $2.2–2.5，可能是这把 key 在别处也用过。要继续生成，需要在 OpenRouter 上调高这把 key 的额度，或者换一把 key。
